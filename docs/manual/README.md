# Claude Task manual

**Last updated:** 27 October 2026.

Claude Task is your team's shared board for planning work and working with Claude Code Agents. Organize Tasks, discuss them with colleagues, ask Agents to make changes, and maintain shared Wikis backed by Git repositories.

Every active User can work on every Project and Wiki. Admins also configure access, Agents and the installation.

## Where to start

- **Team members:** begin with [Getting started](getting-started.md), then [Tasks and conversations](tasks-and-conversations.md).
- **Admins:** start with [Users and access](admin-users.md), then [Agents and credentials](admin-agents.md).
- **Installation operators:** follow [Installation and operations](installation-and-operations.md).
- **Native app users:** see [Native app and notifications](native-app-and-notifications.md).

## Learn and work

1. [Getting started](getting-started.md): sign in and create your first useful Task.
2. [Projects and boards](projects-and-boards.md): organize Tasks, Statuses and Tags.
3. [Tasks and conversations](tasks-and-conversations.md): describe work, assign people, comment and attach files.
4. [Agent sessions and queues](agent-sessions-and-queues.md): start, steer, stop and retry Agent work.
5. [Wikis](wikis.md): ask questions and maintain shared knowledge.
6. [Git repositories and pull requests](git-repositories.md): connect repositories and review changes.
7. [Native app and notifications](native-app-and-notifications.md): open phone navigation, configure Extensions and Git, read cached conversations and receive phone alerts.

## Administer the installation

8. [Users and access](admin-users.md): add Users, reset passwords and manage roles.
9. [Agents and credentials](admin-agents.md): configure Agents and manage their readiness.
10. [Extensions and environment](admin-extensions.md): add Skills, MCP servers, Plugins and Project variables.
11. [Installation and operations](installation-and-operations.md): deploy, configure, back up and recover access.

## Find an answer

13. [Glossary](glossary.md): understand the terms used by the app.
